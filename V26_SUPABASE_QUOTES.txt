V26 — SUPABASE QUOTE STORAGE

What changed:
- Added netlify/functions/quote.mjs.
- Quote submissions are saved into public.quotes using SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY.
- Quote number format: FS-YYYYMMDD-XXXXXXXX.
- Status starts as "new".
- Existing Resend/Twilio notifications are attempted if their environment variables exist.
- Public website design is otherwise unchanged.

Required Netlify environment variables:
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY

Optional notification variables:
- RESEND_API_KEY
- FROM_EMAIL
- TWILIO_ACCOUNT_SID
- TWILIO_AUTH_TOKEN
- TWILIO_FROM_NUMBER
